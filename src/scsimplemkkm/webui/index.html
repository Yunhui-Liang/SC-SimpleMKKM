3. 核配置

默认复现历史 12 核；可让所有视图共享同一 kernel bank，也可为每个 view 单独配置。核配置会进入资源估算、日志和最终结果。

启用名称类型核参数（degree / α / K_scale）support family实际 family

有效参数：等待配置。

Global RBF 约定：exp(-d²/(α·d̄²_v))，其中 d̄²_v 是每个 view 自己的全局平均平方距离。单核主对照固定 α=1（即 RBF7 的中心核），不看标签、不逐数据集挑最优参数；因此同一个 α 在不同 view 上仍会自动得到各自的实际带宽。Self-tuned RBF 使用 exp(-d²/(σ_iσ_j))，σ_i 取第 K_scale 近邻距离（默认 7，Zelnik-Manor–Perona）；k_support 是稀疏图保留邻居数（默认 10）。两者是独立参数：稀疏模式要求 K_scale ≤ k_support，Dense 模式只使用 K_scale。auto support 规则：偶次 s^p 用 abs-cosine，其余用 cosine。
